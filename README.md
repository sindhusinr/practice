vs practice codes

## Git Commands

```bash
git clone <repo>
git add .
git commit -m "Added new code"
git push
```

## Remove Changes

Discard all modified files:

```bash
git reset --hard HEAD
```

Remove untracked files:

```bash
git clean -fd
```

## Check Remote Repository

```bash
git remote -v
```

## Pull Latest Changes

```bash
git pull origin master
```
