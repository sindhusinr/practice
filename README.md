## Git Commands

- git clone <repo>
- git add .
- git commit -m "Added new code"
- git push origin main


## Remove Changes

Discard all modified files:

```bash
git reset --hard HEAD
```

Remove untracked files:

```bash
git clean -fd
```

## Check Remote Repository

`
git remote -v
git branch
`

## Pull Latest Changes

`
git pull origin main
`
